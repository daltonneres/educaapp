# Organização das telas

- `script.js`: dados de demonstração, estado da aplicação e estruturas das telas internas.
- `screens/login.js`: estrutura HTML exclusiva do login.
- `scripts/interactions.js`: validação, navegação e eventos dos controles.
- `style.css`: estilos globais, seleção de perfil e áreas internas.
- `styles/login.css`: estilos exclusivos do login.

Ao personalizar, altere primeiro o arquivo específico da área. Os próximos estilos das telas internas podem seguir o mesmo padrão em `styles/`.
